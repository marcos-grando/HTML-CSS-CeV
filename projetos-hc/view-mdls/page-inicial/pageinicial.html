Projeto Repositório CeV

Repositórios de HTML/CSS e JavaScript

Esse projeto é uma versão aprimorado do primeiro "Projeto Repositório", desenvolvido no Módulo 04 do curso de HTML/CSS do Curso em Vídeo.

Ele reúne os repositórios criados durante as aulas dos cursos de HTML/CSS e JavaScript oferecidos pelo professor Gustavo Guanabara no canal Curso em Vídeo.

⚠️ Versão NÃO funcional para tablets/mobile.

Para explorar o conteúdo, clique na aba do curso desejado à esquerda, selecione o módulo e visualize os projetos diretamente neste iframe.

Este projeto é amador e foi desenvolvido como parte do meu processo de aprendizado. Os códigos JavaScript foram implementados com o auxílio de inteligência artificial.

Contexto do aprendizado:
💻 O curso de JavaScript marcou meu primeiro contato com programação, realizado entre 27/fev/24 e 25/mar/24.
🌐 O curso de HTML/CSS foi minha introdução ao desenvolvimento web, cursado de 03/jun/24 a 29/jul/24.
